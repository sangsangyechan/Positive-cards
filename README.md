# 병현이의 긍정카드 — 모바일 PWA 시제품 (10장)

## 실행
압축 해제 후 해당 폴더에서 `python -m http.server 8000` 실행 → `http://localhost:8000` 접속. `index.html`을 파일로 직접 열면 `cards.json` 로딩이 실패할 수 있습니다.

## 무료 배포
Cloudflare Pages에 폴더 전체를 업로드하거나 GitHub Pages 저장소 루트에 파일을 올리세요. HTTPS 배포 후 Android Chrome 또는 iOS Safari에서 홈 화면에 추가할 수 있습니다. 실제 기기·브라우저별 설치 동작은 확인이 필요합니다.

## 카드 추가
`cards.json`에 id, category, title, message, image를 추가하고 해당 이미지 파일을 images/에 넣습니다. 365장까지 별도 코드 수정 없이 확장됩니다. 이름이 들어갈 자리에는 `{voc}`(호격 포함), `{name}`을 사용하세요.

## 제약
- 테스트용 자수풍 SVG 10장으로, 실제 실물 자수 사진이나 완성된 365장 이미지가 아닙니다.
- 링크 공유는 배포된 공개 HTTPS 주소에서 사용하세요. 이름은 URL 파라미터로 전달되므로 링크를 아는 사람에게 표시됩니다.
- 무료 정적 호스팅의 URL은 기본적으로 공개입니다. 개인 전용 접근 통제는 별도 인증이 필요합니다.
- 오프라인 캐시용 서비스 워커를 등록하지 않았으므로 인터넷 연결이 필요합니다.
- PWA 아이콘은 설치 시 고정된 기본 아이콘이며, 이름을 바꾸더라도 설치 아이콘/앱 이름은 자동 변경되지 않습니다.
- 문구는 친근한 대화체로 새로 작성한 창작물이며 특정 인물의 실제 발언이 아닙니다.
